
# 🚀 **Scaling Microservices with Advanced DevOps Pipelines!**

## 🔹 **Pipeline Highlights**
Each service, such as **cart-service**, **checkout-service**, and **payment-service**, goes through the following flow:
- ⚙️ **Jenkins**: Fully automated builds using Gradle.
- 🔍 **SonarQube**: Continuous code quality enforcement.
- 🔐 **OWASP**: Proactively scanning for dependency vulnerabilities.
- 🐋 **Docker + Trivy**: Creating secure, production-ready containers.
- 📦 **Nexus Private Repository**: Efficient version control and artifact storage.
- ☁️ **Kubernetes**: Cloud-native, scalable deployments across environments.
- 📊 **Prometheus & Grafana**: Real-time observability and actionable insights.
- ✉️ **Automated Notifications**: Ensuring continuous feedback to the team.

---

## 🛠️ **Technologies Used**
- **Microservices**: 11 distinct services for different eCommerce functionalities.
- **Build Tool**: Gradle
- **CI/CD Tools**: Jenkins, SonarQube, Trivy, Nexus
- **Containerization**: Docker
- **Orchestration**: Kubernetes
- **Monitoring**: Prometheus and Grafana
- **Vulnerability Scanning**: OWASP Dependency Check, Trivy
